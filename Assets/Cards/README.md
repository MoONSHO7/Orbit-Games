# Playing-card art

## Description

A generated runtime atlas containing the standard 52-card deck, one card back and the table's dealer chip.

## Purpose

Keep third-party artwork, provenance and rendering coordinates outside card rules and session state.

## Implementation

`PlayingCards.png` is a 2048×512 transparent PNG generated by `../../Dev/Assets/BuildCardAtlas.py`. Four suit rows contain ranks 2 through ace; row five contains the back and a 64×64 dealer chip. Each 128×88 landscape card fills the face with one oversized rank and suit, without a decorative footer. Single-character ranks share a fixed 62-pixel visible height; only 10 scales down to fit the same rank region. The back uses the same pinned source with a higher-contrast treatment.

`PlayingCards.json` records the pinned upstream revision, typography contract, exact component source filenames, card ID and pixel rectangle for all 53 card cells. Its separate decoration entry records the dealer-chip rectangle, checksum and project-generated provenance. Runtime code derives texture coordinates from those fixed atlas constants rather than parsing JSON.

The source is `hayeah/playing-cards-assets` at commit `1e4497c05c3da9956c9f517bd386e9a7090ff7fa`. Its processed assets are MIT licensed; `LICENSE.playing-cards-assets` is packaged unchanged. The upstream README identifies the original vector-playing-cards artwork as public domain.

The dealer chip is original Orbit-Games art drawn only from Pillow primitives: a dark edge and D, gold ring and ivory face. It uses no third-party font or image.

## Gotchas

- Never replace the atlas without running the generator and its `--check` mode.
- Face ranks come from the pinned diamond cards and suit marks from the pinned two of each suit. This avoids font dependencies while keeping every glyph attributable to the packaged licence.
- Keep the project-generated dealer chip outside the 53-entry card identity list; it is decoration, never a playable card.
- Runtime texture paths must include the `.png` extension; WoW does not infer it for PNG assets.
- Preserve the pinned commit, upstream copyright and complete MIT notice in every package containing the derived atlas.
- Jokers are intentionally excluded. Domain card IDs cover only the standard 52-card deck.
